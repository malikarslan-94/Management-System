# CampWise feature drafts for approval

Four desktop design concepts for the currently disabled sidebar entries. These use the existing CampWise theme and fictional sample data. No application frontend or backend changes are included.

| Screen | Proposed behavior |
| --- | --- |
| [Check-In / Check-Out](01-check-in-out.png) | Daily check-in/out queue, overdue stays, reviewed checkout, Available or Cleaning room state |
| [Facilities](02-facilities.png) | Shared-space cards, camp/type/status filters, add/edit form, operating hours and maintenance status |
| [Reports](03-reports.png) | Current occupancy, resident roster, movement history, facility register, preview, CSV and print/PDF |
| [Settings & Roles](04-settings-roles.png) | User accounts, four role templates, assigned-camp access, active/inactive accounts and preferences |

Read [the full design proposal](design-proposal.md) for fields, workflows, permissions, error states, initial scope and backend dependencies.

Decisions to review: rename Recreation Facilities to Facilities; keep existing room-level assignments; default checked-out rooms to Cleaning; use four fixed roles; defer bookings, bed-level allocation and historical occupancy trends.

Images were produced using the built-in image generation tool. The full [prompt set](generation-prompts.md) is included for future revisions.
