TROUBLESHOOTING: "querySrv ENOTFOUND" ERROR
==============================================

If you're getting: "querySrv ENOTFOUND _mongodb._tcp.cluster0.2sxwz.mongodb.net"

SOLUTION 1: Get the correct connection string from MongoDB Atlas
------------------------------------------------------------------
1. Log in to MongoDB Atlas: https://cloud.mongodb.com
2. Go to your cluster
3. Click "Connect" button
4. Select "Connect using MongoDB Compass"
5. Copy the connection string provided (it will be the correct one)
6. Replace <password> with your actual password: malikarslan
7. Use that connection string in MongoDB Compass

SOLUTION 2: Verify Cluster Exists
----------------------------------
1. Check if the cluster "cluster0.2sxwz" still exists in your Atlas account
2. The cluster might have been deleted or renamed
3. Verify the cluster name in MongoDB Atlas dashboard

4. Port: 27017
5. Authentication: Username/Password

7. Password: malikarslan
8. Authentication Database: admin
9. SSL/TLS: Enabled
10. Additional Options:
    - retryWrites=true
    - w=majority

- cluster0-shard-00-02.2sxwz.mongodb.net:27017

SOLUTION 4: Check Network/DNS
------------------------------
1. Check your internet connection
2. Try using a different network (mobile hotspot)
3. Check if your firewall is blocking DNS queries
4. Try using a VPN if DNS is restricted in your region

SOLUTION 5: Verify IP Whitelist
--------------------------------
1. Go to MongoDB Atlas → Network Access
2. Make sure your current IP address is whitelisted
3. Or add 0.0.0.0/0 for development (not recommended for production)

SOLUTION 6: Check Credentials
-----------------------------
1. Verify username and password are correct
2. Check if the user exists in MongoDB Atlas → Database Access
3. Make sure the user has proper permissions
